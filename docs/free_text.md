# 自由长句与词语简拼

2026-11-01：在已验证小游戏/有声书v10之上开发，已独立部署并完成两轮代表性真实眼控检查。新UI为v11，原四大目标、1秒停留、300ms有效移开、个人模型与位流保持。文字仍只在本屏显示，不自动朗读或发送。

从“文字输入→自由输入”选择“词语简拼”或“完整拼音”。简拼每字取首字母，如今天JT、下午XW、音乐YY；zh/ch/sh只取z/c/s。输入一个字母时先显示单字；要组词，选右下“继续简拼”后补下一字母。单字“午”简拼为W，完整拼音为WU；简拼不会接入该字的后续韵母。最多6个首字母。候选每页两项，下一组循环，选一字或一词后回到简拼字母页继续。所有加入都需新的明确停留，不自动拼出整句。候选较多时可切回完整拼音。

词库包含5000个原有汉字及12010个2–6字词语：来自已在工程内固定版本保存的MIT词频与读音数据，另含13个手工连接片段。新增词库419006字节，不下载新依赖，不联网推断。常用首读音和11项明确多音词读法优先，保留最多16种初声组合。已有常用表达及个人收藏可提高相关候选顺序，原候选不删除；不写入学习日志。仍可能遇到生僻词、罕见读音或简拼重码，需要翻页或使用完整拼音，不是通用中文输入法的等效替代。

“修改/完成”可删除一个未完成简拼字母，或通过“查看候选”回到原候选页，不改正文和首字母；简拼为空时，可撤销最近一次正文编辑，按加入的一字或一词撤销，不影响收藏。撤销历史只在内存保留最近16步；退出程序后不保留，也不恢复已经删除的收藏。进入“输入方式”可切换完整拼音、输入标点数字。切换方式保留各自未完成的拼音/简拼；确认载入收藏、确认清空会清理两种待输入内容。未收藏草稿不会跨进程保存。

正文与收藏单句上限由32字扩至64字，收藏仍最多12句。空间不足时整词不加入，已有正文和简拼保留，不截断内容。大字展示使用同一28像素字形、最多四行，帮助与返回仍在原下方位置；旧收藏可直接载入。64字是容量边界，不表示真人已经输入过64字。
