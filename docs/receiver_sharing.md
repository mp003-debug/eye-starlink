## 使用方式

保留独立升级目录与服务，显式增加 `--receiver-sharing`，同时启用 `--eye-events live` 和原日常工具依赖。无线及分享默认关闭，不修改自启动。`--eye-events log` 用于真实眼控输入、接收端不显示内容的TEST检查。

入口：更多 → 快捷交流 → 文字输入 → 编辑展示 → 接收屏分享。原正文、收藏、输入法及休闲功能保留。没有启用分享参数时沿用原页面。

| 内容 | 发送方式 | 接收屏行为 |
| --- | --- | --- |
| 是、不是、请停一下、请帮我换个姿势、我要上厕所、我不舒服 | 选择固定表达，再确认发送 | 交流表达页，不触发红灯 |
| 开心、难过、担心、喜欢、谢谢、想你 | 选择心意文字，再确认发送 | 情绪心意页，不发送本机图片或新增语音 |
| 输入正文 | 固定正文快照 → 完整预览 → 继续确认 → 确认发送 | 最长64字，完整接收后显示，草稿与收藏不变 |
| 活动摘要 | 本次运行内明确开启，默认关闭，随类别变化发送 | 显示上次活动，两分钟未更新标为过时，不据此判断离线 |

活动仅包含菜单、音乐、视频、听书、游戏、相册、文字交流、展示心意类别；不发曲名、书名、照片、视频、声音、正文或每次游戏操作。变化最多每5秒一次，连接不可用时丢弃当次更新，不补发旧活动；关闭后不再自动更新，并尝试发送关闭提示。关闭提示若失败，旧活动仍按原规则标为过时。

正文限1–64个可打印GB2312字符。不支持的生僻字或符号明确提示，不替换、不截断。引号与反斜杠按屏幕文本语法转义。“三端已接纳”只表示应用接纳，不表示屏幕已完成刷新或护理人员确认。提交包在途时取消/断链显示“接纳结果不确定”，不能宣称远端撤回。
