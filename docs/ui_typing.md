## 输入方式

文字输入页四个入口为“拼音输入 / 常用表达 / 编辑展示 / 返回”。拼音只显示词典允许接在当前拼音后面的字母；拼成音节时直接进入候选。若音节还没拼完，例如ha后还要输入o，选择右下“继续拼音”。单独m、n等少见音节可从“修改/完成→选字”进入候选。全部411个词典音节仍可达。

选中汉字后清空拼音并直接继续输入下一个字。“修改/完成”提供选字、删除、展示收藏和返回输入页。删除仍先删未完成拼音，再删正文；不删除收藏。已有常用句与当前正文末尾能匹配时，将相应候选字排到前面，其余候选保持原顺序；不增加在线模型、学习日志或存储写入。

“常用表达”提供日常需要、交流心意各10句，以及原有“我的收藏”。每页两句，下一组和返回；选择后整句追加到正文并进入展示/收藏操作页，不自动展示、不播音、不发送。未完成的拼音保留。空间不足时整句不加入，不截断或覆盖草稿。正文32字、收藏12句上限及原子保存方式保持。

## 按钮与页面

所有按钮继续使用原四大目标范围，文字中心对齐已校准的注视位置；没有缩小按钮或增加密集小目标。圆角、细边框、图标与顶部装饰预先生成，不闪烁、不播放装饰动画。

动态页面仅在内容改变时混合字形，停留和光标更新只复制缓存。已选择提示和进度继续明确显示；无效输入仍立即清零，翻页后仍要有效移开300ms，再重新停留1秒。150ms新鲜度、模型、分类器、参考采集、位流、音频和无线规则均未改。
