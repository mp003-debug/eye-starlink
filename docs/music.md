## 眼控行为

- 音乐默认关闭，仅显式 `--music` 的有声eye-trial启用；要求配套音频IP v2和源码/版本3界面素材。无线仍默认off。
- 主页面四按钮不变。“更多”进入功能菜单，左上进入音乐、右下返回主页。音乐页依次为左上播放/暂停、右上下一首、左下帮助、右下返回。
- 换页后需在原触发区外保持有效输入300ms，再开始新一轮完整停留。闭眼或无效输入不能绕过此门。
- 正常暂停在完整立体声帧边界生效，恢复沿当前位置继续。下一首在播放时立即切歌；暂停时切换曲目后等待显式播放。末曲下一首回到第一曲；自然结束停音，不自动续曲/循环。
- 帮助优先中止音乐并播放原帮助语音，播完保持暂停。再次播放从已消费样本位置继续；抢占可能打断正在发送的样本重复片段，和正常精确暂停不同。
- 返回音乐页上级时停音并清位置；BTN0/BTN1暂停音乐且不自动续播，BTN2清校准和BTN3退出停音。识别无效立即清停留，但已主动开始的音乐不会因普通眨眼停播。
- 只有一个音频硬件拥有者，短语与音乐不同时播放。缺数、失钟、播放停滞或暂停应答超时会停音并退出当前运行，记录故障，不重播旧缓冲冒充正常连续输出。
- 音乐/新增导航键只作本地动作；帮助仍沿原规则可在另行显式启用无线后发送。未扩展02/03/04协议或固件。

## 连续播放实现

原64KiB音频RAM保留，v2将其分成两个16384样本的缓冲区，每区1.024秒；PS有界读取文件、填充空闲区，PL保持I2S时钟连续消费。无需把整首歌读入内存，无音频DMA或后台硬件线程。数组转换/读回会产生有界临时副本；实际板上RSS和填充余量仍待测。

AXI基址0x43C20000、地址范围128KiB不变；ID仍AUD1，版本0x00020000。原短语单缓冲模式保留，软件在短语开始前切回模式0。

| 偏移 | v2含义 |
| --- | --- |
| 0x08 | START=1、STOP=2、CLEAR=4；PAUSE=8、RESUME=16。STOP立即清播放和缓冲所有权 |
| 0x0C | busy/done/fault/clock_alive为bit0–3；paused/underrun/pause_pending为bit4–6 |
| 0x30 | 停止时选择模式：0短语、1连续播放 |
| 0x34 | bit0/1表示两区已交PL，bit2表示当前区；交付后禁止PS修改 |
| 0x38/0x3C | 提交bank0/1，低位长度1–16384，bit31表示末块，其他位为0 |
| 0x40 | 本轮播放已消费样本数 |
| 0x10000/0x18000 | 两区PCM16数据首地址；每区32KiB |

16kHz样本仍各重复三个48kHz帧，左右声道相同。最后一个样本完整输出后才报告结束或欠载，禁止提交/覆盖PL拥有的缓冲。暂停期间失钟仍终止。
