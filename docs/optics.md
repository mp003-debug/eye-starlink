## 2. 镜头选择：先看瞳孔像素数

能在35cm对焦，只说明焦点能落到该距离。2.8mm广角镜头即使换成无IR-cut版本，在相同距离下仍给瞳孔留下相近的少量像素；数字放大和ROI裁剪不会增加原始采样细节。

以下为选型用的理想薄透镜估算，非实际眼图或精度：像元间距p=0.006mm，捕获区域640×480，传感器不做binning；u近似取320/350mm，实际镜头主平面位置、畸变、光圈、近红外像质和角膜折射均未建模。m=f/(u-f)，物方视场宽=640p/m，目标直径像素数=d*m/p。4mm是示例目标尺寸，不代表已测得用户的瞳孔直径。

| 焦距 | 32–35cm处水平视场，640列裁剪 | 假设4mm目标直径 | 选型判断 |
| --- | --- | --- | --- |
| 原配/同焦距2.8mm | 约43.5–47.6cm | 约5.4–5.9像素 | 先做采集、对焦及视场基线，不优先买同焦距红外替换件作为主方案 |
| 8mm | 约15.0–16.4cm | 约15.6–17.1像素 | 较大视场的对照候选 |
| 12mm | 约9.9–10.8cm | 约23.7–26.0像素 | 首个单眼特写试验的优先候选，需核对机械适配和对焦 |

小瞳孔会更困难：同模型35cm、3mm示例目标在2.8mm镜头下约4.0像素，在12mm下约17.8像素。任何像素数都不是准确眼控的充分条件。较长焦距缩小可见区域，必须同时实测完整眼区、头动和景深；表中视场不能直接当成允许的头动范围。后续如输出全幅752列，水平视场可增加17.5%，同一个目标所占的原生像素数不会增加；当前位流仍输出640列，未作此改动。

估算可复现：

```powershell
python D:/Eye_tracker_system/tools/estimate_optics.py
```

默认输出[build/optics/estimate.json](../build/optics/estimate.json)。脚本仅执行几何计算，不访问相机、不控制补光、不生成眼控有效标记。

### 当前镜头规格方向

2026-10-21更新：用户已下单MTV12MP5C（12mm/F2.8/M12×0.5），商家转述无IR-cut、支持850nm且适配原镜座，待到货实测。先用这一只建立35–40cm基线，再分别验收30–45cm的调焦、固定焦点清晰度和校准移动容差；不追加8mm对照镜头。镜尾净空与传感器盖玻璃仍须按实物检查，不强行旋到底。

“定焦”通常指焦距固定，不必然表示不能调焦。需要确认的是实际工作距离能否调清楚，以及是否有足够机械调节空间。去掉IR-cut会同时接收可见与近红外，不等于加了850nm带通片；带通片留待环境干扰实测后判断。

### 现在可做的原装成像检查

板端采集适配就绪后，在普通稳定室内光下，把带50mm刻度跨度的直尺放在计划眼部平面，分别测量镜头前方约32cm和35cm，尺面尽量与成像面平行、刻度跨度位于画面中央。固定相机和尺子，记录实际距离。原始帧按640×480、1:1保存，关闭预览缩放对测量的影响，记录是否存在binning/其他缩放。

在原始帧中测量50mm跨度的像素距离n，得到中心附近的n/50像素/mm，与估算作数量级比较。按暂定2.8mm模型，约应为67–74像素/50mm；偏差先排查真实镜头参数、距离、畸变、调焦和采集缩放。没有采集到画面前不填写实测值，也不拿UI截图或插值图替代。

确认具体替换镜头适配并拿到实物后，断电、固定好模组，再按镜头/镜座说明松开锁紧螺钉并更换镜筒；不拆镜座、不撬滤片、不触碰传感器盖玻璃，不强行旋到底。换镜头后先用普通目标对焦，850nm下最终焦点在非人体台架上复核；几何或光源位置变化后重新标定。

| 配套限流驱动 | 匹配LED、硬件电流上限、默认关闭、手动关闭、必要的使能接口 | 未选型；不以软件PWM替代硬件限流 |
| 供电与支架 | 按驱动额定输入选电源；可调固定架和线缆应力保护 | 先核对现有配件 |

初期可以只设计一个独立照明单元和可调位置；以实际反光点身份验证决定是否需要增加光源，不直接堆叠多灯。光源数/位置改变都应触发重新标定。

电气关系是“合适电源 → 配套限流驱动 → LED”。未来由PL控制时，GPIO只接符合3.3V逻辑要求的驱动使能/同步输入，非隔离控制需要共地；具体引脚和供电等型号确定后绘制，不能先猜。摄像头LED_OUT是同步信号，不能直接作为补光供电。现有Pmod和转接板不接新增大电流负载。

## 4. 先台架，再眼部成像

先在不照射人的台架上检查驱动限流、实际电流、默认关闭、温升、相机响应、曝光与增益。人眼试验前，需要对实际灯板、镜头/光学件、最小可能观看距离、驱动状态、持续时间及可预见故障条件取得光生物安全评估依据。仅凭850nm、低电功率、看不见或LED元件资料都不能推定整机安全；商用眼控仪的认证也不能套用到自制灯板。没有测量条件时，优先使用适用条件明确的已评估照明组件，并由具备相应测量能力的实验室复核组合后的条件。

安全条件明确后，再采集重复中心、上下左右/四角、自然小幅头动、闭眼、遮挡和离框原始图。记录曝光、增益、瞳孔像素数、反光点位置/面积、饱和情况和几何配置。相机I2C及双上下文手动曝光/增益恢复已实现并上板；不把偶然清晰的一帧当作稳定结果。

验收目标是看清真实瞳孔边界和对应光源的角膜反射，且注视变化可重复区分。虹膜外圈、眼皮阴影、眼镜/环境高亮都不能直接当作目标特征。校准与检查采用不同采集序列。
