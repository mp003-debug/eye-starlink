# Third-party components and publication scope

The root MIT license applies to original EyeStarlink code and the reusable Skill.
It does not relicense the following components or upstream vendor material.

| Component / location | License and source |
|---|---|
| `assets/fonts/noto_sans_cjk_sc.otf`, derived glyph atlases | SIL OFL 1.1; `assets/fonts/license.txt`; pinned source/hash in `assets/fonts/sources.json` |
| `assets/typing/pinyin.json` / word dictionary inputs | MIT; `assets/typing/pinyin_license.txt`, `jieba_license.txt` and `attribution.json` |
| `assets/haarcascade_eye.xml` | OpenCV upstream license/copyright included in the XML header |
| `assets/ai/minimind_q8.bin`, tokenizer | MiniMind2-Small, Apache-2.0; `assets/ai/licenses/minimind.txt`; quantized by this project from pinned revision in `build/edge_ai_v2_20261103/vendor/sources.json` |
| Adapted `tiny_run.c`, `win.h` and `vendor/llama2c` | MIT, Andrej Karpathy; upstream license retained in `vendor/llama2c/LICENSE`; changes include bounded shape/context, ARM NEON and local token I/O |
| `assets/music/` | Individual CC BY / CC BY-SA recording licenses and transformation details in `attribution.json`; not relicensed MIT |
| `assets/photos/` | CC BY-SA 3.0 / CC0 photographs, author/source/changes in `album.json`; derivative mountain image remains CC BY-SA |
| AMD Vivado / PYNQ / WS63 SDK | External tools/platform components under their own terms; not bundled as an open-source SDK here |

The project-authored RISC-V application logic is included. Generated vendor
configuration headers are regenerated by the pinned SDK; the SDK itself and
prebuilt vendor-linked firmware are not redistributed in this repository.
The public CMake glue selects only project application sources and uses the SDK's
existing parent-scope build interface. See `docs/reproduce.md`.

The public tree excludes private eye captures/calibration weights, local account
data, proprietary font files, synthesized commercial-voice recordings and compiled
serial-screen project files. Their application code, source texts, UI generators,
interface specifications and resource import tools remain available.

eSpeak NG and its libraries are optional external GPL/LGPL components. Obtain
them from their upstream/distribution source and retain their licenses; the
repository includes the project-authored file-only audio adapter source, not the
prebuilt eSpeak binaries. A downstream binary distribution must satisfy the
upstream source and notice requirements.
